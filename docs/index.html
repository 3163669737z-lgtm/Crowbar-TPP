Crowbar-TPP

面向 Windows 的模型反编译与模组工具。支持《求生之路 2》分离网格、更多 MDL 格式，以及 VTF 文件头修复。

A Windows MDL decompiler and modding toolkit with Left 4 Dead 2 model export, VTF header repair, and a high-DPI Simplified Chinese interface.

Windows 下载 查看源码

x86 便携包 · .NET Framework 4.8

新增功能

更多 MDL 格式

完善 Half-Life Alpha v4 和 007: Nightfire PC v14 的模型导出，支持 Dreamcast v10 的 PowerVR 纹理和 Xash3D v10 的扩展顶点数据。

《求生之路 2》分离网格与导出

自动识别采用 Source v49 布局的模型并匹配外置 VVD 和 VTX。支持指定配套资源目录，按条件导出可用数据和带表情的 DMX。

VTF 文件头修复

检查 PC VTF 7.0–7.2 二维纹理的数据布局，符合要求时可另存仅修正头长度的副本。

简体中文与高 DPI

补全常用界面、菜单和日志的简体中文，支持不同缩放比例的多显示器环境。
