Crowbar-TPP

基于 Crowbar 与 Crowbar-Starfelll 的修改版，支持 Left 4 Dead 2 分离网格、Source v49 Delta 动作还原、更多 MDL 格式及 VTF 文件头修复。

A Crowbar / Crowbar-Starfelll fork with Left 4 Dead 2 model export, Source v49 Delta animation restoration, VTF header repair, and a high-DPI Simplified Chinese interface.

Windows 下载 查看源码

x86 便携包 · .NET Framework 4.8

主要改动

Left 4 Dead 2 分离网格与导出

自动识别 v53 声明、v49 布局的模型并匹配外置 VVD / VTX，修正异常命名，导出带表情的 DMX 并保留 SMD，便于 StudioMDL / NekoMDL 重编译。

Source v49 Delta 动作还原

反编译含 Delta 增量序列的模型时自动还原为绝对姿态 SMD，可直接导入 Blender 编辑，并支持通过 StudioMDL / NekoMDL 无损重编译。

更多 MDL 格式与 VTF 修复

新增 Half-Life Alpha v4、007: Nightfire PC v14、Dreamcast v10 与 Xash3D v10 反编译支持，内置 PC VTF 7.0–7.2 文件头修复工具。

简体中文与高 DPI

补全中文界面、菜单与日志输出，升级至 .NET Framework 4.8 并支持每显示器高 DPI 缩放。
